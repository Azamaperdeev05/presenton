## 🌟 Жоба туралы

**Presenton** — кез келген тақырыпта кәсіби, көз тартарлық презентацияларды жылдам жасауға арналған ашық бастапқы кодты (open-source) қуатты платформа. 

Бұл репозиторийде жоба **қазақ тіліне толықтай бейімделіп**, отандық пайдаланушылар мен білім беру, бизнес және мемлекеттік сала мамандарына арналған арнайы Smart мүмкіндіктермен, жаңа логотиппен, жергілікті macOS қосымшасымен және жоғары сенімділік архитектурасымен толықтырылды.

## 🚀 Негізгі мүмкіндіктер

### 1. 🇰🇿 Толық Қазақ Тілді Интерфейс пен AI Генерациясы
- Барлық батырмалар, мәзірлер, нұсқаулықтар, баптаулар және көмекші мәтіндер табиғи қазақ тілінде сөйлейді.
- Презентация жасау тілі әдепкі бойынша **Қазақ тілі** етіп бекітілген.
- Жасанды интеллект слайд жоспарын, тезистерін және толық мазмұнын қазақ тілінің орфографиялық нормаларына сәйкес сауатты қалыптастырады.

### 2. ⚡ Smart Генерация Режимі
- Қарапайым бір сөйлемнен немесе тақырыптан бастап, жүйе тақырыптың мазмұнын автоматты түрде талдайды.
- Слайдтың ең қолайлы түс палитрасын, типографикасын, құрылымын және логикалық блоктарын өздігінен үйлестіреді.

### 3. 🛡️ Аккаунтсыз Тікелей Жұмыс (Guest / No-Auth Mode)
- Артық тіркелуді немесе логин-пароль енгізуді күтпей-ақ, бағдарламаны ашқан бойда бірден презентация құрастыруға кірісуге болады.

### 4. 🎨 Заманауи Және Эксклюзивті Дизайн
- Жаңартылған ресми минималистік логотип пен таза қараңғы/жарық тақырыптар (Dark/Light mode).
- Интерактивті drag-and-drop слайд редакторы.
- Сапалы суреттер, диаграммалар және визуализация блоктары.

### 5. 📑 Толық Өңделетін Экспорт (PPTX & PDF)
- Дайын презентацияны Microsoft PowerPoint (`.pptx`) форматында жүктеп алып, кез келген элементін, мәтінін, қаріптерін өңдеуге болады.
- Баспаға немесе көрсетілімге арналған жоғары сапалы PDF форматы да қолжетімді.

### 6. 🤖 Кез келген LLM Модельдерін Қосу
- Google Gemini (Gemini 2.5 Flash / Pro, т.б.)
- OpenAI (GPT-4o, GPT-4o-mini)
- Жергілікті офлайн модельдер: Ollama, LM Studio
- Кез келген OpenAI-үйлесімді API провайдерлері (Groq, Together AI, DeepSeek, т.б.)

## 🛠️ Архитектура және Жаңа Жақсартулар

Бұл нұсқада орын алған техникалық жақсартулар мен архитектуралық жаңалықтар:

### 📡 1. SSE Heartbeat Тұрақты Ағыны (Chat Stream Fix)
* **Мәселе**: Үлкен слайдтар мен көп сатылы AI функциялары орындалғанда (~30 секундқа дейін), желілік прокси мен браузер уақыт шегіне (timeout) ұшырап, байланыс үзілетін (`Chat stream ended before completion`).
* **Шешім**: `servers/fastapi/utils/sse.py` ішіне Server-Sent Events (SSE) ағынына 3 секунд сайын бос уақытта автоматты `: ping\n\n` хабарламаларын жіберетін heartbeat механизмі енгізілді. Анти-буферизация тақырыптамалары (`X-Accel-Buffering: no`, `Cache-Control: no-cache, no-transform`) қосылып, чат байланысы 100% тұрақты болды.

### 🔄 2. Backend Health Check & Smart Retry
* **Мәселе**: Бағдарлама қосылғанда Next.js мен FastAPI қатар іске қосылып, базалық миграциялар жүріп жатқанда фронтенд бірден қате беретін (`BackendConnectionError`).
* **Шешім**: `servers/nextjs/utils/api.ts` ішінде `assertBackendReachable()` функциясына 10 ретке дейін қайта тексеру (retry backoff) жүйесі енгізілді. База толық жүктелгенше пайдаланушыға қате көрсетілмейді.

### 🍏 3. macOS Native Қолданбасы (`Presenton.app`)
* Жоба үшін арнайы Swift (`scripts/PresentonApp.swift`) негізінде жеке macOS Native қосымшасы жинақталды.
* WKWebView арқылы браузердің артық құралдар тақтасынсыз, нағыз десктоптық қосымша сияқты жұмыс істейді.
* Фондық режимде FastAPI (8000) мен Next.js (3000) процестерінің дайындығын тексеріп, жүктелу экранын (Splash screen) көрсетеді.

## 💻 Жылдам Іске Қосу Нұсқаулығы

### 1-әдіс: Автоматты скрипт арқылы (Барлық платформалар үшін)
Жоба папкасындағы бірыңғай іске қосу скриптін пайдаланыңыз:

```bash
chmod +x run-local.sh
./run-local.sh
```

Бұл скрипт:
1. Python виртуалды ортасын (`.venv`) тексереді және қажетті бумаларды орнатады.
2. FastAPI серверін `http://localhost:8000` портында іске қосады.
3. Node.js бумаларын орнатып, Next.js клиентін `http://localhost:3000` портында көтереді.
4. Дайын болғанда браузеріңізді автоматты түрде ашады.

---

### 2-әдіс: Әзірлеушілер үшін жеке-жеке іске қосу (Manual Dev)

#### 1. Серверді (FastAPI) іске қосу:
```bash
cd servers/fastapi
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Клиентті (Next.js) іске қосу:
```bash
cd servers/nextjs
npm install
npm run dev
```
Браузерден `http://localhost:3000` мекенжайына өтіңіз.

## 🍏 macOS Қосымшасы (`Presenton.app`)

Егер сіз macOS қолдансаңыз:
1. `scripts/start-presenton.sh` арқылы немесе `Desktop/Presenton.app` белгішесін басу арқылы қосымшаны дербес терезеде ашуға болады.
2. Қосымша жабылғанда барлық фондық серверлер авто-өшіріледі (`scripts/stop-presenton.sh`).
